# 국립스포츠박물관 개관 기념 이벤트 미니 홈페이지 (초안)

모바일 우선 원페이지 정적 사이트입니다. 서버·빌드 도구 없이 `index.html` + `assets/` 만으로 동작합니다.

## 로컬 확인

```bash
python3 -m http.server 8000
# http://localhost:8000 접속 (모바일 화면은 브라우저 개발자도구 기기 모드 권장)
```

## 구성

| 섹션 | 내용 |

| 히어로 | 개관 D-day(자동 계산), "먼저 만나는 국립스포츠박물관", 시범운영 안내, CTA 2개, 건물 일러스트 + 캐릭터 |
| 즐길거리 | 자녀와 함께하는 체험존 / 우리나라 스포츠 역사관 / 다양한 기획전과 현장 이벤트 |
| 전시 미리보기 | 전시실 사진 1장 |
| 선물 이벤트 | 무료 관람 + 돗자리 증정 안내 |
| 오시는 길 | 약도 위 **이동 동선 애니메이션 강조**(출발·도착 핀, 흐르는 점선, 걷는 아이콘), 3단계 길안내, 주소 복사, 네이버지도/카카오맵 버튼, 대중교통 |

- 개관일 `26.10.15.(목)`, 시범운영 `10월 10일(토) 17:30까지`, 즐길거리 3종, 무료 관람·돗자리 증정, `평화의 광장에서 도보 5분 이내`, 주소 `서울시 송파구 올림픽로 424` → 제공받은 공식 포스터 2종

- 지하철 8호선 몽촌토성(평화의문)역 → 평화의 광장 인접 역(일반 지리 정보). **담당자 확인 권장**

## 배포 전 확인 사항

1. 건물 일러스트를 공식 외경 사진으로 교체 (`assets/building-illust.jpg`, 16:10 비율 권장)
2. 돗자리 이미지 교체 여부, 증정 조건(수량·대상) 문구 확정
3. 대중교통·주차 안내 문구 확정, 문의 전화번호 추가 여부
4. 관람시간·휴관일 등 운영 정보가 확정되면 "개관 안내" 섹션에 추가
5. 웹폰트(Pretendard)는 jsDelivr CDN을 사용합니다. 사내망에서 CDN이 막히면 시스템 폰트로 자동 대체됩니다.
